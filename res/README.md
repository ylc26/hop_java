# Ressources optionnelles

Placez dans ce dossier les ressources utilisées par l’interface :

- `luigi25.png`
- `mario.png`
- `volcan1.jpg`
- `volcan2.jpg`
- `son_hop.wav`

Le programme peut être compilé sans ces fichiers. Des formes et couleurs de remplacement sont utilisées pour les images manquantes ; la musique reste désactivée si le fichier audio est absent.
